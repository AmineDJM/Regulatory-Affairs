# Audit du 04/10/2026 — bugs, interface, doublons, contrôles inutiles

Constats relevés pendant le chantier (mesurés ou lus dans le code — c'est indiqué). Rien n'est corrigé ici :
la Direction choisit. Gravité : **C** critique · **H** haute · **M** moyenne · **B** basse.

## A. Stockage et téléversements (perte de documents)

1. **C** — Faux « téléversé » : si l'écriture du fichier échoue, l'erreur est avalée, la fiche est créée, l'écran dit « ok » ; le fichier est ensuite « indisponible » (`documents.ts:52`, `attach-files.ts:66`). *Mesuré.*
2. **C** — La purge des fichiers « orphelins » ignore 11 tables qui référencent un fichier (messagerie, documents RH, pièces Regulatory, rapports terrain, papier en-tête, logo…) et se déclenche aussi AUTOMATIQUEMENT à chaque suppression définitive d'un élément du Drive (`drive-storage.ts:297`, `database-admin-actions.ts:41`). *Démontré sans lancer la purge.*
3. **C** — Copier un fichier du Drive n'incrémente pas le compteur du fichier partagé : supprimer copie + original rend le document d'origine illisible (`drive-actions.ts:624`). *Mesuré.*
4. **H** — Suppression et dépôt simultanés du même contenu : 19 à 31 dépôts « réussis » sur 40 illisibles ; erreurs techniques brutes affichées (`drive-storage.ts:279`, `releaseBlob`). *Mesuré.*
5. **H** — Postgres gratuit (≈1 Go, expiration) déclaré dans `render.yaml` : sans S3, les fichiers vont en base → base pleine → perte silencieuse via (1). *À vérifier dans Render.*
6. **H** — Mémoire : 858 Mo après un ZIP de 60 Mo (tout en mémoire, pas de flux) — crash probable sur une instance à 512 Mo. *Mesuré en local.*
7. **H** — Sponsoring : une pièce refusée laisse la demande créée → doublon au second essai (`sponsoring-actions.ts:255`).
8. **M** — Une tâche perd une pièce refusée sans message (`task-actions.ts:76`).
9. **M** — Deux listes de types de fichiers différentes : `.rar`, `.7z`, `.msg` passent à un endroit, refusés à l'autre.
10. **M** — Envoi en deux clics : quitter la page entre les deux perd la sélection sans avertir (`document-upload.tsx`).
11. **M** — Pas de contrôle de taille avant l'envoi → erreur générique « Body exceeded ».
12. **B** — Nom accentué mal enregistré au téléchargement sous Firefox/Safari (`filename=` au lieu de `filename*=`).
13. **B** — Fichier vide écarté sans message ; seule la première erreur d'un lot s'affiche ; une relance réseau peut créer une « v2 ».
